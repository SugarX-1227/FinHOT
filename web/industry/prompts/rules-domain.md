
【财经领域写作与翻译规则 — 本平台是 A 股投资者看的财经资讯，严格遵守】

1. 数字与单位一字不改：
   - 金额、比例、同比环比、基点、点位、价格、区间保留原文的阿拉伯数字和单位（亿元、万亿元、美元、%、个百分点、基点 bp、点、元/吨）
   - 不换算单位，不把“12000 亿元”改写成“1.2 万亿元”或反过来；不把 $10B 改写成“上百亿美元”这类模糊说法
   - 区分“百分比”和“百分点”：利率、占比的变化用“个百分点”或“基点”，不能写成“%”
   - 实际值、预期值、前值都在原文出现时一起保留，不要只写其中一个
2. 时间与时区：原文写“美东时间”“北京时间”“当地时间”的照抄；不把美国数据的发布时间换算成别的时区；相对时间照抄，不补年份。
3. 股票与代码：公司简称照原文写；原文带股票代码（如 600519.SH、00700.HK）的保留；不要把公司简称改成全称或另一个简称。
4. 常用英文缩写保留英文，不加中文括注：GDP / CPI / PPI / PMI / LPR / MLF / SLF / PSL / FOMC / ETF / IPO / QDII / QFII / ESG / EPS / ROE / OPEC / IMF
5. 海外机构与术语按惯用中文翻译：
   - Federal Reserve / Fed = 美联储；FOMC = 联邦公开市场委员会（可保留 FOMC）；ECB = 欧洲央行；BOJ = 日本央行；BOE = 英国央行；Treasury = 美国财政部（指国债时译“美债”）
   - nonfarm payrolls = 非农就业人数；jobless claims = 初请失业金人数；yield = 收益率；hawkish / dovish = 鹰派 / 鸽派；rate cut / hike = 降息 / 加息；basis point = 基点
   - S&P 500 = 标普 500；Nasdaq = 纳斯达克 / 纳指；Dow = 道指；Brent / WTI 保留英文
6. 海外公司优先用通行中文名：Apple = 苹果；Nvidia = 英伟达；Tesla = 特斯拉；Microsoft = 微软；Alphabet / Google = 谷歌；Amazon = 亚马逊；Meta 保留英文；TSMC = 台积电；Samsung = 三星。中国公司用官方中文名。
7. 政策与文件名称照原文写，带书名号的保留书名号；不要把“征求意见稿”写成“正式出台”，不要把“拟”“计划”写成“已经”。
8. 不使用“暴涨”“暴跌”“血洗”“史诗级”等夸张说法，原文用了也改为客观描述（“大涨 7%”“下跌 5%”）。
